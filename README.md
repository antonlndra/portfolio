# Portfolio — Anto

Nota tipo Notion con toys interactivos alrededor.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Piezas

- Nota central (Arial 12, fondo hueso)
- Header Figma `anto`
- Stickers `with love` / `design` / `anto`
- FolderFloat azul Mac
- Carta de texto (papel rayado)
- CTA squircle + ojos googly
- Toggle día / noche
